# Home Server Operations

家庭服务器的运维知识与任务管理仓库。由本地 Codex 核验服务器事实、维护任务和执行验收，Web ChatGPT 读取仓库获取上下文并指导用户执行具体任务。

## 当前状态

- 2026-10-21：建立本地仓库和协作约定。
- 服务器连接信息尚未提供，尚未核验服务器架构、配置或服务状态。
- 远程仓库尚未配置，尚未推送。

以上是仓库建立时的状态；后续核验应记录来源及核验时间，不能将历史记录当作实时状态。

## 协作流程

1. 本地 Codex 根据证据整理现状，准备任务目标、范围、约束及验收标准。
2. Web ChatGPT 读取仓库，检查任务前提，再指导用户执行一个边界清晰的任务。
3. 用户将实际执行结果交回本地 Codex。
4. 本地 Codex 通过已授权的只读访问和执行证据核验结果，检查项目一致性并更新文档。
5. 审查 Git Diff 和敏感信息，形成边界清晰的提交；配置远程仓库后按约定推送。

任务说明、已执行操作和已验收结果必须明确区分。缺少关键验证证据时，保留待验证状态。

## 仓库边界

本仓库保存有效的项目事实、技术决策、任务及经过脱敏的必要证据；不用于服务器配置同步或部署。

不保存凭据、私钥、环境文件、运行数据、数据库、上传文件、备份或原始日志。必要的配置片段和验证摘要需经过脱敏，并注明来源与时间。

文档按实际需要逐步增加，避免空模板和重复记录。自动化助手的工作约定见 [AGENTS.md](AGENTS.md)。
